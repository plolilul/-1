# 데이터 입출력 프로그램

간단한 서버-클라이언트 구조의 웹 기반 데이터 입출력 프로그램입니다.
- 서버: Node.js + Express (REST API 제공, JSON 파일에 데이터 저장)
- 클라이언트: 브라우저(HTML/CSS/JS)에서 서버 API를 호출하여 데이터를 입력/조회/삭제

## 실행 방법

```bash
npm install
npm start
```

서버는 기본적으로 `0.0.0.0:8000`에서 실행되어 같은 네트워크의 다른 기기에서도 접속할 수 있습니다.

- 서버를 실행한 컴퓨터에서: `http://localhost:8000`
- 같은 네트워크의 다른 기기(크롬)에서: `http://192.168.25.141:8000` (서버 컴퓨터의 실제 IP로 접속)

> 서버를 실행하는 컴퓨터의 IP 주소가 `192.168.25.141`이어야 위 주소로 접속됩니다.
> `ipconfig`(Windows) 또는 `ifconfig`/`ip a`(Mac/Linux)로 실제 IP를 확인하세요.
> 포트나 호스트를 바꾸려면 `PORT=8000 HOST=0.0.0.0 npm start` 처럼 환경변수로 지정할 수 있습니다.

## 기능

- 제목/내용을 입력해 데이터 저장 (POST /api/items)
- 저장된 데이터 목록 조회 (GET /api/items)
- 데이터 삭제 (DELETE /api/items/:id)

데이터는 `data/items.json` 파일에 저장되어 서버를 재시작해도 유지됩니다.
